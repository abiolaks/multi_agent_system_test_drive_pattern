# Thresholds are pre-extracted from PDF guidance into structured form

Thresholds live inside PDF maintenance manuals (one per Asset Model) as structured tables. Because code must compare Readings against them reliably, the threshold tables are pre-extracted once per model into structured, queryable records rather than read live from the PDF by the LLM. The structured records live in a small version-controlled store the code reads directly (a JSON/YAML file in the repo for the POV; a database or Fabric table in production) — they are NOT placed in the Azure AI Search RAG index, which exists only for the LLM's narrative retrieval. The PDFs remain the source of truth for narrative Fault-Signature guidance; extracted threshold tables are kept in sync when a manual is revised.
